SMARTGEST SCHOOL — SITE VITRINE

Fichier principal : index.html

PUBLICATION AVEC GITHUB + RENDER
1. Créez un dépôt GitHub PUBLIC nommé smartgest-school-site.
2. Téléversez index.html à la racine du dépôt.
3. Sur Render : New + > Static Site.
4. Connectez le dépôt GitHub smartgest-school-site.
5. Paramètres : Branch main ; Root Directory vide ; Build Command vide ; Publish Directory .
6. Cliquez sur Deploy Static Site.
7. Copiez l’adresse HTTPS fournie par Render.

À COMMUNIQUER À COUSSEMA
Collez l’adresse publique du site dans le champ « Lien du site web de votre projet ou page Facebook » pour la demande du Sender ID SMARTGEST. L’approbation reste à la décision de Coussema.

IMPORTANT : Ne mettez jamais votre clé API Coussema, mot de passe ou autre secret dans ce site ou dans GitHub.
